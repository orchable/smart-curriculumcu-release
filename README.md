# Smart Curriculum Release

> Automated release pipelines and distribution workflows for AI-driven learning material generation systems and smart curriculum components.

## 🚀 Overview

`smart-curriculum-release` is the centralized release and distribution hub for the [Orchable](https://orchable.app) ecosystem. This repository manages automated workflows, packaging, and versioning for AI-powered learning material generators (học liệu), interactive curriculum modules, and educational tools.

## 🛠️ Features

- **Automated Pipelines:** Streamlined GitHub Actions workflows for building, testing, and publishing curriculum releases.
- **Asset Distribution:** Centralized management of generated educational packages, templates, and runtime components.
- **Versioning Control:** Semantic versioning tracking for smart learning modules and system updates.

## 📦 Structure

- `.github/workflows/` — Automated CI/CD release and deployment pipelines.
- `assets/` — Distribution packages, templates, and release artifacts.
